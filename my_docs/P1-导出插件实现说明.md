# P1：AngelscriptTypeExporter 导出插件实现说明

> 仓库：`d:\WorkGit\UEProjs\Demo_AS`
> 上游设计：`d:\WorkGit\my-angel-script-lsp\docs\架构设计.md`（§2 模块一）
> 语法规范：`d:\WorkGit\my-angel-script-lsp\angelscript.bnf`
> 行为基准：引擎侧 `FAngelscriptDebugServer::SendDebugDatabase`（`Engine/Plugins/Angelscript/Source/AngelscriptCode/Private/Debugging/AngelscriptDebugServer.cpp`）

## 1. 这是什么

一个 **项目级 Editor 插件**，把 Angelscript 引擎（C++ 绑定）注册的全部类型导出为 `.d.as` 声明文件（AngelScript 语法的声明子集，无函数体）。导出物供 my-angel-script-lsp（P2/P3）离线消费，使 hover / 跳转 / 引用 不需要启动引擎。

**数据源与 DebugDatabase 完全一致**（同一个 `asCScriptEngine` 的类型注册表），逐段对齐了 DebugServer 的导出逻辑（见 §5 对照表），保证 LSP 侧行为与现有 Hazelight LSP 一致。

**关键差异**：DebugServer 会连脚本类一起发送；本插件**过滤 `asOBJ_SCRIPT_OBJECT`**（脚本类/struct/funcdef），因为它们能从 `.as` 源码完全推导，导出反而制造双源冲突。

## 4. 输出格式

### 4.1 目录与文件

```
Demo_AS/Saved/AS-Cache/
├── _manifest.dctx        # 清单（见 4.4）
├── Engine.d.as           # 分组 = UClass/UScriptStruct 所在 UPackage（/Script/Engine → Engine）
├── UMG.d.as
├── Core.d.as             # 无法归入 UE 包的类型（含模板 TArray<TMap<...>> 定义等）
├── Global.d.as           # 全局函数/变量（无 namespace）
└── Math.d.as             # namespace 分组（namespace 名即文件名，:: 替换为 .）
```

分组规则（`ResolveClassGroup` / `ResolveNamespaceGroup`）：
1. **类型**：能通过 `FAngelscriptType` 映射到 `UStruct`/`UClass` → 按 `GetPackage()->GetName()` 的最后一段（REF 类型兜底用 `ScriptType->GetUserData()`）；都失败 → `Core`；
2. **namespace**：namespace 名命中已知 UClass（组件访问器 namespace，如 `USpringArmComponent{ Get/GetOrCreate/Create }`）→ 合并进该类所在模块文件（v2 修正，避免一类一小文件）；否则独立成文件（namespace 名，空 namespace → `Global`）。

> 注意 `Saved/` 会被"清理项目"清空且不入 git——这是设计意图（导出物是缓存）。需要版本化时把 `AS-Cache` 目录拷入版本库，LSP 侧用 `typeDeclarationDirs` 配置指向。

### 4.2 文件头

每个 `.d.as` 前五行：

```angelscript
// ==== AngelscriptTypeDeclarations ====
// @cache_format 1
// @group Engine
// Generated by AngelscriptTypeExporter - do not edit.

```

### 4.3 声明形式与注解标签

**类型**（继承链取"最近的 Angelscript 可表达父类"，与 DebugServer 相同的 FAngelscriptType 上溯算法）：

```angelscript
// Dot product of two vectors.          ← doc（FAngelscriptDocs，多行自动拆行）
// @keywords math;vector                ← UClass 的 ScriptKeywords 元数据（逗号→分号）
struct FVector : ...                    ← asOBJ_VALUE → struct，否则 class
{
    float X;                            // 属性
    protected int Hidden;               // isProtected → protected 语法
    // @editable                        // DebugServer flags 0x2（仅默认值可编辑）
    float OnlyInDefaults;

    FVector(float X, float Y, float Z); // 构造（factory/construct behaviour）

    // @event                           // UFunction FUNC_BlueprintEvent
    // @ufunction                       // FUNC_BlueprintCallable|Pure
    // @unrealname K2_GetActorLocation  // AS 名与 UFunction 名不同时
    // @outputTypeIndex 0               // determinesOutputTypeArgumentIndex（已扣 hidden 参数）
    // @defaultsOnly                    // IsSetterAndOnlyValidDuringInitDefaults
    // @notCallable                     // asTRAIT_NOT_CALLABLE
    // @notProperty                     // IsProperty()==false 时才标注（反向编码，见 4.4）
    // @meta DelegateBindType=...       // 4 个 Delegate 元数据 + SCRIPT_BIND_MANUAL_BIND_META
    FVector GetActorLocation() const;   // const 方法尾缀
    TArray<FVector> GetArray() const;
}

// @template_covariant                  // asOBJ_TEMPLATE_SUBTYPE_COVARIANT
class TArray<T>                          // 模板定义：GetSubType 列表作为类型参数
{
    T Get(int Index) const;
}
```

**模板特化**（对特定实例追加的方法，来自引擎 `registeredTemplateSpecializationFunctions`）：

```angelscript
// @templateSpecialization
class TArray<FVector>
{
    void ExtraMethodOnlyOnFVectorArrays();
}
```

**枚举**（归组按 UEnum 的包；值 doc 来自 UEnum ToolTip）：

```angelscript
enum ECollisionChannel
{
    // World static object
    WorldStatic = 0,
    WorldDynamic = 1,
}
```

**命名空间 / 全局**：

```angelscript
namespace Math
{
    float Sqrt(float Value);
}

// Global functions and variables (no namespace)
float Abs(float Value);
int GSomeGlobal;
```

### 4.4 参数与类型渲染规则（与 DebugServer 逐条对齐）

| 规则 | 实现 |
|---|---|
| 类型声明 + 引用后缀 | `GetTypeDeclaration(typeId)`；`const` 不加后缀，`&`/`&out`/`&in` 按 `asTM_*` flags 附加 |
| `const T&in` 补全 | `(INREF|CONST)` 且**非模板成员函数**时 `const X&in`（对齐 DebugServer :1562） |
| 蓝图事件 float 参数 | `float32` 且非引用 → 显示为 `float`（:1569） |
| 参数默认值 | `GetParam(..., defaultArg)` → `Type Name = default` |
| 隐藏参数 | `hiddenArgumentIndex` 跳过；`@outputTypeIndex` 已减 1 |
| `__` 前缀 | 函数名、参数名、全局变量名、类型名全部跳过 |
| 未命名参数 | 生成 `InArg0`、`InArg1` 占位名（**.d.as 语法要求参数有名字**，见 P2 注意事项） |
| `?` 类型参数 | `ttQuestion` 参数输出为 `? Name`（app interface 形参） |
| 生成访问器 | `Get*/Set*` + `asTRAIT_GENERATED_FUNCTION` → 合并为属性行（:1663-1700 同款逻辑） |
| **属性访问器语义** | 复刻 DebugServer 的 `isProperty` 反向编码：**仅 `IsProperty()==false` 时输出 `@notProperty`**（全量实测 69337 成员仅 12 个）。C++ 绑定默认 `SetProperty(true)`（`bAllowImplicitPropertyAccessors=true`），P3 对 `.d.as` 函数默认按访问器处理，索引层配对 `Get*/Set*`（getter 0 参 / setter 首参，对齐 `asCCompiler::FindPropertyAccessor` + `AS_GET/SET_PREFIX`）为虚拟属性——`x.BaseValue` ⟷ `GetBaseValue()/SetBaseValue()` 两种写法都合法，**不能**在导出时直接合并为属性行（会丢 setter 重载/getter 默认参/unrealname，且 references 需双写法覆盖） |

**为什么真实绑定的 Get/Set 不烘焙成属性行（设计决策，勿改）**：导出器对"配对规范性"分流——① `asTRAIT_GENERATED_FUNCTION` 的生成访问器对（严格 1:1、零参 getter/单参 setter、无重载无 unrealname）**烘焙**为属性行；② 真实绑定的 Get/Set（可有重载/默认参/`@ufunction`/`@unrealname`/Get 与 Set doc 不同）**保持方法**+trait，由 P3 索引期合成虚拟属性投影。理由：官方 LSP 的模式是"函数为唯一真值、属性是出口投影"（补全投影成 Field 候选、跳转落 getter、references 双向合并、rename 前缀手术），烘焙等于固化投影、制造第二真值；且引擎配对是名字导向、类型宽松（编译器 TODO 未实现类型匹配检查），setter 重载/带默认参 getter（`GetAttachedActors(bool=false)`，官方合成条件 `args.length==0` 不满足）只能以方法形态保留。分界与 DebugServer `:1663-1700` 的生成访问器属性化完全一致。
| deprecated | 方法跳过（asTRAIT_DEPRECATED）；属性跳过（isDeprecated，WITH_EDITOR） |
| funcdef / 脚本类型 | `asOBJ_FUNCDEF`、`asOBJ_SCRIPT_OBJECT` 整体跳过 |

```

exported_utc=2026-09-26T14:00:00
type_count=1234
member_count=56789
```

- `cache_format`：`.d.as` 格式版本（**格式不兼容变更时必须 bump**，当前 1）；

- `files`：本次导出的完整文件清单（LSP 据此发现文件）。

## 6. 已知简化 / 后续改进点

1. **isProperty 字段未导出**——DebugServer 对 `IsProperty()==false` 的方法标 `isProperty:false`（LSP 用于区分属性访问器）。`.d.as` 里方法声明形式天然非属性，P2 解析端默认即可；若 golden 对照发现差异再补 tag。
2. **enum inherits 未导出**（DebugServer 也未发）。
3. **分组 v1 用 UPackage/namespace**——按 Bind 注册文件分组的方案（设计文档 §2.2 方案 a）待调研 `FAngelscriptBinds` 可枚举性。
4. **`bIsBlueprintEvent` 的返回值 float 规则只作用于参数**——DebugServer 对返回值没有同样处理（对齐）。
5. **输出无排序去重保证跨版本稳定**——类型按 `GetObjectTypeByIndex` 顺序、namespace 按 TMap 遍历序。若要 diff 友好（导出物入库场景），后续加按名排序开关。

## 8. 与 P2/P3 的接口约定

- **P2（tree-sitter）**：`.d.as` 需要在 BNF 基础上支持两处小扩展——①类名后可选 `<T, ...>` 类型参数（模板定义）；②参数允许 `? Type` 形式（app interface）。均已在 BNF §3.2 DATATYPE 的 `?` 与模板产生式中预留。
- **P3（Rust 核心）**：消费顺序 = 读 `_manifest.dctx` 校验版本 → 按组加载 `.d.as` → 声明进符号库（`declaredModule == null` 语义，等价旧 LSP 的 Unreal 类型）→ 与 `.as` 源码解析的符号合并（脚本声明优先，参照 `AddUnrealTypeToDatabase` 的 `declaredModule` 顶替规则）。
- **tag 语义**：见 §4.3，全部是声明前 `// @tag [value]` 行，doc 与 tag 混排时 tag 在 doc 后。
